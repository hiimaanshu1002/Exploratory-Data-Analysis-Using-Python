# Heart Disease Exploratory Data Analysis (EDA) – Final Project

## Dataset Description

The dataset used in this project is the Heart Disease UCI dataset, which contains medical information of patients used to analyze and predict the presence of heart disease. Each row represents a patient, and each column represents a clinical attribute.

The dataset includes features such as:

Age
Sex
Hospital Location
Chest pain type
Resting blood pressure
Cholesterol(mg/dl)
Fasting blood sugar
Resting ECG results
Maximum heart rate achieved
Exercise-induced angina
ST depression (oldpeak)
Slope of ST segment
Number of major vessels blocked
Thalassemia


## Objectives:

- Identify relations between different medical parameters
- Clean Data for irregularities
- Create new features

---

- Numpy

---

## Summary

Heart disease is more common in older individuals, especially above 40 years of age.
Male patients showed a higher prevalence of heart disease compared to females.
Patients having higher than normal cholestrol levels, are shown to have some heart disease.
Number of blocked vessels, ST depression, ECG results, Chest Pain type all help to understand the severity of the disease.
Multiple features analysis was more useful than single variable analysis.
